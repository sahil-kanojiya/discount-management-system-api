# Discount Management System API

Promotional discount and coupon validation engine built with Spring Boot.

## Features
- Coupon code generation, activation, and expiration scheduling.
- Percentage-based and fixed-amount discount calculation rules.
- Cart order eligibility verification and validation endpoints.

## Tech Stack
- Java 21 LTS
- Spring Boot, Spring Data JPA
- MySQL
- Maven Wrapper

## Running
```bash
./mvnw clean compile
./mvnw spring-boot:run
```
